CAT - Coral Annotation Tool (desktop, portable)
================================================

1. Unzip this folder anywhere (Desktop, Documents, a USB stick).
2. Double-click CAT.exe. No installer and no admin rights are needed.

First run: Windows may show "Windows protected your PC" because the app is
not code-signed. Click "More info", then "Run anyway".

Imagery is streamed from the public NOAA bucket, so an internet connection
is required. The "data" folder will hold settings, cache and logs.

Keyboard: mouse wheel = zoom, drag = pan, F = fit, ? = all shortcuts.
